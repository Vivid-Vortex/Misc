```
**TypeScript Coding Guideline:**
Keep TypeScript simple, readable, maintainable, and Java-like. Prefer straightforward types, interfaces, basic generics, arrays, objects, Map, Set, and common built-in utility types such as Partial, Record, Pick, and Omit when they simplify the code. Avoid advanced TypeScript type-level programming, complex mapped/conditional types, clever type tricks, excessive generics, and unnecessary abstractions. Prioritize code that is easy to understand and maintain over highly clever or sophisticated TypeScript. Only use advanced TypeScript features when they are genuinely required by the problem, framework, or library.
```
