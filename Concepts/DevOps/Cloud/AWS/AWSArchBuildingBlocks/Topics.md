# AWS Architectural Building Blocks

You should strengthen **AWS**, but don't try to learn 50 services.

Focus on the **architectural building blocks**:

## Compute
- EC2
- ECS
- Lambda

## Networking
- VPC
- Subnets
- Security Groups
- Load Balancer
- API Gateway

## Storage
- S3

## Database
- RDS
- DynamoDB
- ElastiCache

## Messaging
- SQS
- SNS
- MSK / Kafka

## Security
- IAM
- KMS
- Secrets Manager

## Observability
- CloudWatch

---

The important part isn't memorizing services.

It's being able to say:

> "For this requirement, I would choose ECS instead of Lambda because..."

That's **architecture**.
