ssh-keygen -t ed25519 -C "your_email@example.com"
simply replace your github email in the above command and paste it in ubuntu or git bash terminal and follow the prompt. Use some easy to remember passphrase. And rest is self explanatory step.
At the end you will get two with same name. one among them will be extension like .pb. open it and copy the key
and paste it in the ssh key in github.
Guide given in below pages.
