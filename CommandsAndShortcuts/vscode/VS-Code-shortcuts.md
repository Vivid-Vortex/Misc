### 🧩 IntelliJ vs VS Code Shortcut Mapping

| **IntelliJ Shortcut**     | **What It Does in IntelliJ**                                      | **VS Code Equivalent**                                                                             |
| ------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `Ctrl + Shift + F12`      | Maximize/Restore editor (hide all tool windows)                   | `Ctrl + K, Z` → Zen Mode or `Ctrl + B` to toggle sidebar                                           |
| `Ctrl + F12`              | Show file structure (outline of classes/methods in current file)  | `Ctrl + Shift + O`                                                                                 |
| `Ctrl + Tab`              | Switch between open files and tool windows                        | `Ctrl + Tab`                                                                                       |
| `Ctrl + F1` to `Ctrl + 9` | Focus on specific tool windows: `F1 = Project`, `F6 = TODO`, etc. | No exact shortcut, but: `Ctrl + Shift + E` → Explorer `Ctrl + J` → Problems (can customize others) |
| `Ctrl + Shift + F`        | Search across entire project (global find)                        | `Ctrl + Shift + F`                                                                                 |
| `Double Shift`            | Search everywhere: files, classes, actions, symbols               | No default; closest is `Ctrl + P` + `@` or install **"Search Everywhere"** extension               |
|                           |                                                                   |                                                                                                    |
|                           |                                                                   |                                                                                                    |
|                           |                                                                   |                                                                                                    |

---

### ✅ Notes:

- IntelliJ uses `Ctrl + F1 → 9` to focus various **tool windows**; in VS Code you mostly access these from the **View menu** or with **custom keybindings**.
    
- For `Double Shift` behavior, you can simulate it in VS Code using:
    
    - `Ctrl + P` → for files
        
    - `Ctrl + Shift + P` → for commands
        
    - `Ctrl + T` → for symbols in workspace
        
    - Or install an extension like **"Search Everywhere"**

> What are the shortcuts for **"move backward"** and **"move forward"** in IntelliJ IDEA, and what are their equivalents in VS Code?

---

### 🔄 Move Backward / Forward (Navigation History)

|**Action**|**IntelliJ IDEA Shortcut**|**VS Code Shortcut**|
|---|---|---|
|**Navigate Backward**|`Ctrl + Alt + Left Arrow (←)`|`Alt + Left Arrow (←)`|
|**Navigate Forward**|`Ctrl + Alt + Right Arrow (→)`|`Alt + Right Arrow (→)`|

---

### 💡 What It Does:

- These shortcuts help you jump between your previous **cursor locations**, **file jumps**, or **method navigations**—very useful when switching between definitions and usage points.
